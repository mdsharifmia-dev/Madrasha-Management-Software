## 🌟 Overview / সংক্ষিপ্ত পরিচিতি

**Madrasha Management Software** হলো বাংলাদেশের কওমি ও আলিয়া মাদ্রাসাসমূহের সম্পূর্ণ প্রশাসনিক, আর্থিক, শিক্ষাগত, ছাত্রাবাস এবং যোগাযোগ ব্যবস্থার একটি আধুনিক, নিরাপদ এবং স্কেলেবল **Multi-Tenant SaaS ERP Platform**।

এটি একটি একক প্ল্যাটফর্মের মাধ্যমে সেন্ট্রাল সুপার অ্যাডমিন এবং দেশের যেকোনো মাদ্রাসার মুহতামিম/অ্যাডমিনিস্ট্রেটরদের জন্য স্বাধীন সাব-ডোমেইনে স্বয়ংসম্পূর্ণ পোর্টাল সরবরাহ করে।

## 🚀 Key Features / প্রধান মডিউলসমূহ

### ১. 🏢 মাল্টি-টেন্যান্ট সুপার অ্যাডমিন প্ল্যাটফর্ম (Super-Admin SaaS Hub)
- **মাদ্রাসা অনবোর্ডিং:** বিভাগ, জেলা ও থানা ভিত্তিক কওমি ও আলিয়া মাদ্রাসার রেজিস্ট্রেশন ও লাইসেন্স অনুমোদন।
- **প্যাকেজ ও সাবস্ক্রিপশন বিলিং:** বেসিক, স্ট্যান্ডার্ড ও এন্টারপ্রাইজ প্যাকেজ ব্যবস্থাপনা এবং স্বয়ংক্রিয় রিনিউয়াল ট্র্যাকিং।
- **সেন্ট্রাল অডিট ও মনিটরিং:** সিস্টেম হেলথ, মেমোরি কনজাম্পশন, লাইভ সকেট সংযোগ ও অ্যাক্টিভিটি লগিং।

### ২. 💰 হিসাব, মেস ও ক্যাশ ক্লোজিং (Finance, Accounts & POS)
- **বহুমাত্রিক তহবিল:** সাধারণ চলতি তহবিল, মেস/বাজার তহবিল, মেরামত ও স্থায়ী তহবিল, ছাত্র কল্যাণ ও লিল্লাহ তহবিল।
- **মেস ও বাজার খরচ:** দৈনিক কাঁচামাল কেনাকাটা, ভাউচার এন্ট্রি এবং ক্যাশ ক্লোজিং রিকনসিলিয়েশন।
- **বেতন ও পেরোল:** ওস্তাদ ও স্টাফদের মাসিক বেতন শিট তৈরি ও ডিসবার্সমেন্ট।
- **অপরিবর্তনীয় লেজার (Immutable Ledger):** কোনো আর্থিক এন্ট্রি পরিবর্তন বা মোছা যায় না; রিভার্সাল এন্ট্রির মাধ্যমে শতভাগ অডিট ট্রেইল সংরক্ষিত থাকে।
- **কাস্টমাইজেবল রিপোর্টিং:** দৈনিক, মাসিক, বাৎসরিক বা কাস্টম তারিখ অনুযায়ী রিসিট ও ভাউচার এক্সপোর্ট।

### ৩. 📖 হিফজ ও শিক্ষা ব্যবস্থাপনা (Academic & Hifz Progress)
- **হিফজ ট্র্যাকার:** দৈনিক সবক (নতুন পড়া), সাত সবক এবং আমোখতা (পেছনের পড়া) ৩-টিয়ার ট্র্যাকিং।
- **বেফাকুল মাদারিসিল আরাবিয়া স্ট্যান্ডার্ড:** কওমি জামাত কাঠামো (ইবতিদায়িয়া থেকে দাওরায়ে হাদিস) ও আলিয়া কারিকুলাম সাপোর্ট।
- **পরীক্ষা ও ফলাফল:** টার্মিনাল পরীক্ষা, মারকাজ রোল নম্বর, গ্রেডিং এবং স্বয়ংক্রিয় প্রগ্রেস রিপোর্ট কার্ড।

### ৪. 🛏️ ছাত্রাবাস, ডাইনিং ও গেটপাস (Hostel, Mess & Safety)
- **ছাত্রাবাস রুম ম্যানেজমেন্ট:** ভবন, ফ্লোর ও রুম অনুযায়ী সিট বণ্টন।
- **ডিজিটাল মিল কাউন্টিং:** সাধারণ ছাত্র ও লিল্লাহ ফান্ডে খাবার গ্রহণকারীদের রিয়েল-টাইম তালিকা।
- **সিকিউর গেটপাস:** অভিভাবকের সম্মতি, ওস্তাদের ডিজিটাল অনুমোদন এবং কিউআর কোড ভেরিফিকেশন সহ ছুটি বা জরুরি গেটপাস।

### ৫. 📚 লাইব্রেরি (মাকতাবা)
- আরবি, উর্দু, ফার্সি, ইংরেজি ও বাংলা কিতাবের ক্যাটালগিং ও বারকোড ট্র্যাকিং।
- তলবা ও আসাতেজা কেরামের কিতাব ধার ও ফেরত রেকর্ড।

### ৬. 📱 এসএমএস ও দ্বি-ভাষিক অভিভাবক পোর্টাল (Communication)
- **BTRC স্ট্যান্ডার্ড বাংলা এসএমএস:** উপস্থিতি, বকেয়া ফি ও জরুরি ছুটির এসএমএস অ্যালার্ট কিউ (BullMQ + Redis)।
- **অভিভাবক অ্যাপ এপিআই:** অভিভাবকরা ঘরে বসেই ছাত্রের সবক প্রগ্রেস, পরীক্ষার রেজাল্ট ও ফি হিস্ট্রি দেখতে পারেন।

## ⚡ দ্রুত শুরু (Quick Start Guide)

### ১. ক্লোন ও প্রজেক্টে প্রবেশ
```bash
git clone https://github.com/mdsharifmia-dev/Madrasha-Management-Software.git
cd Madrasha-Management-Software
```

### ২. এনভায়রনমেন্ট ফাইল প্রস্তুত
```bash
cp .env.example .env
```

### ৩. ডিপেন্ডেন্সি ইনস্টলেশন
```bash
npm install
```

### ৪. ডকার ডাটাবেস ও রেডিস চালু
```bash
docker compose up -d
```
* **PostgreSQL:** `localhost:5432`
* **Redis:** `localhost:6379`
* **Adminer Web GUI:** `http://localhost:8080`

### ৫. ডাটাবেস মাইগ্রেশন
```bash
npx prisma db push --schema=apps/api/prisma/schema.prisma
```

### ৬. ডেভেলপমেন্ট সার্ভার চালু
```bash
# Core API সার্ভার চালু করুন (Port 4000)
npm run dev:api

# Frontend Web ড্যাশবোর্ড চালু করুন (Port 5173)
npm run dev:web
```

## 🔒 নিরাপত্তা নীতি (Security Standards)

1. **Zero-Trust Secrets:** কোনো এপিআই কি, পাসওয়ার্ড বা টোকেন কোডবেসে হার্ডকোড করা নেই। সবকিছু পরিবেশ ভ্যারিয়েবল (`.env`) দ্বারা নিয়ন্ত্রিত।
2. **আর্থিক অপরিবর্তনীয়তা (Financial Immutability):** কোনো ট্রানজাকশন হিস্ট্রি মুছে ফেলা যায় না। ভুল সংশোধনে কেবল কাউন্টার-ভাউচার গ্রহণযোগ্য।
3. **মাল্টি-টেন্যান্ট ডেটা নিরাপত্তা:** এক মাদ্রাসার হিসাবরক্ষক অন্য মাদ্রাসার কোনো তথ্য দেখার সুযোগ নেই।
4. **Timezone Accuracy:** বাংলাদেশ সময়ের সাথে মিলিয়ে সমস্ত ডেটাবেজ রেকর্ড `Asia/Dhaka` টাইমজোনে নিবন্ধিত হয়।
