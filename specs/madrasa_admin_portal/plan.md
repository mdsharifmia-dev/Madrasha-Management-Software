# Technical Architecture & Implementation Plan: Madrasa Admin Portal
**ফিচার:** মুহতামিম অ্যাডমিন ড্যাশবোর্ড ও ডিপার্টমেন্টাল আইকন গ্রিড
**তারিখ:** ১৯ অক্টোবর ২০২৬ | **অবস্থা:** Approved for Implementation

## ১. কম্পোনেন্ট ও আর্কিটেকচার ডিজাইন

### ১.১ ডেটা স্ট্রাকচার: `Department` ইন্টারফেস
```typescript
interface DepartmentItem {
  id: string;
  nameBn: string;
  nameEn: string;
  code: string;
  iconName: string; // e.g. 'CreditCard', 'Scale', 'BookOpen', 'Users', 'Bed', 'GraduationCap', etc.
  category: 'FINANCE' | 'ACADEMIC' | 'ADMIN' | 'FACILITY';
  assignedStaff: { id: string; name: string; role: string; phone: string; status: 'ACTIVE' | 'HOLD' }[];
  status: 'ACTIVE' | 'HOLD' | 'UNASSIGNED';
  statsSummary: string;
  badgeColor: string;
  iconBgColor: string;
  routeKey: string;
}
```

### ১.২ স্টেট আর্কিটেকচার (In `App.tsx`)
1. `departments`: ১২টি ডিপার্টমেন্টের অ্যারে (আইকন, নাম, দায়িত্বপ্রাপ্ত উস্তাদ/স্টাফের তালিকা, স্ট্যাটাস, সংক্ষিপ্ত পরিসংখ্যান)।
2. `activeNav`: 
   - ডিফল্ট যখন কোনো মাদ্রাসায় প্রবেশ করা হবে: `setActiveNav('madrasa_dashboard')`।
   - সাইডবার বা গ্রিড থেকে কোনো ডিপার্টমেন্টে ক্লিক করলে নির্দিষ্ট রুটে যাবে (যেমন `'finance'`, `'academic'`, `'hostel'`, `'library'`, `'sms'` অথবা মডাল ভিউ)।
3. `deptMenuOpenId`: কোন ডিপার্টমেন্টের ৩-ডট মেনু বর্তমানে ড্রপডাউন আকারে খোলা আছে।
4. `deptAccessModal`: ৩-ডট মেনু থেকে কোনো ডিপার্টমেন্টের অ্যাক্সেস ম্যানেজ করার মডাল (স্টাফ নিয়োগ, পারমিশন পরিবর্তন, হোল্ড বা রিমুভ)।

### ১.৩ ড্যাশবোর্ড গ্রিড লেআউট ডিজাইন
- **শীর্ষ ব্যানার:** মুহতামিম স্বাগত সম্ভাষণ, প্রতিষ্ঠানের নাম, হিজরি ও ইংরেজি তারিখ, একাডেমিক সেশন।
- **ডিপার্টমেন্টাল স্কয়ার আইকন গ্রিড (Responsive 15cm / 200px equivalent tile layout):**
  - Grid: `grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-4 gap-6`
  - প্রতিটি কার্ড:
    - স্কয়ার / প্রোপরশনাল কার্ড (প্যাডিং `p-6`, কার্ভড `rounded-3xl`, ডার্ক/লাইট মোড সমর্থিত ব্যাকগ্রাউন্ড ও বর্ডার)।
    - টপ রো: বড় রঙিন আইকন কনটেইনার (`w-14 h-14 rounded-2xl flex items-center justify-center`) + ডিপার্টমেন্ট স্ট্যাটাস ব্যাজ (সক্রিয় / হোল্ড) + ৩-ডট বাটন।
    - মিডল রো: ডিপার্টমেন্টের নাম (বাংলা ও সাব-টাইটেল ইংরেজি), মূল পরিসংখ্যান (যেমন: "আজকের আদায়: ৳৮৪,৫০০", "১৮৫ জন সবক দিচ্ছেন", "১,৯২০ মিল বরাদ্দ")।
    - বটম রো: দায়িত্বপ্রাপ্ত উস্তাদের নাম ও প্রবেশাধিকার স্ট্যাটাস + "বিভাগে প্রবেশ করুন" বাটন।

### ১.৪ সাইডবার অ্যাক্সেস কন্ট্রোল
- সাইডবারে ডিপার্টমেন্টের নামের পাশে ৩-ডট মেনু থাকবে।
- ৩-ডটে ক্লিক করলে পপওভার খুলে যাবে যেখানে:
  - 👤 কার অ্যাক্সেস আছে
  - ⏸️ অ্যাক্সেস সাময়িক বন্ধ (হোল্ড)
  - ❌ অ্যাক্সেস বাতিল
  - ⚙️ দায়িত্ব পরিবর্তন

## ২.১ নতুন ফিচার আর্কিটেকচার ও ডেটা মডেলসমূহ

### ক. নোটিশ মডেল (`AdminNotice`)
```typescript
interface AdminNotice {
  id: string;
  title: string;
  content: string;
  priority: 'URGENT' | 'NORMAL';
  targetDeptIds: string[]; // 'ALL' অথবা নির্দিষ্ট ডিপার্টমেন্টের আইডি সমূহ
  sender: string; // 'মুহতামিম অফিস'
  createdAt: string;
  isRead?: boolean;
}
```

### খ. চলতি অনুমোদন ও পারমিশন মডেল (`ApprovalRequest`)
```typescript
interface ApprovalRequest {
  id: string;
  title: string;
  departmentName: string;
  deptCode: string;
  requesterName: string;
  amount?: string;
  type: 'FINANCE' | 'WAIVER' | 'LEAVE' | 'REQUISITION' | 'GATEPASS';
  date: string;
  status: 'PENDING' | 'APPROVED' | 'REJECTED';
  urgency: 'HIGH' | 'NORMAL';
  description: string;
}
```

### গ. রুলস ও পারমিশন মডেলসমূহ (`PolicyRule` ও `StaffPermission`)
```typescript
interface PolicyRule {
  id: string;
  code: string;
  title: string;
  module: string;
  description: string;
  status: 'ACTIVE' | 'INACTIVE';
}

interface StaffPermissionGrant {
  id: string;
  staffName: string;
  departmentId: string;
  departmentName: string;
  role: string;
  permissionLevel: 'VIEW' | 'EDIT' | 'APPROVE' | 'FULL_ACCESS';
  status: 'ACTIVE' | 'HOLD';
  assignedDate: string;
}
```

## ৩. লেআউট পরিবর্তন ও ইউআই উপাদান (UI Layout Changes)

1. **ডিপার্টমেন্ট কার্ডের লেন্থ অর্ধেক (Half-Length App Tiles):**
   - ড্যাশবোর্ডে ৪-কলামের বদলে ৬-কলামের রেসপনসিভ গ্রিড (`grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-6 gap-2.5`)।
   - কার্ডের দৈর্ঘ্য প্রায় অর্ধেক হবে, যাতে স্ক্রিনের পুরো প্রস্থ জুড়ে অযথা প্রসারিত না হয়ে সুবিন্যস্ত ও কমপ্যাক্ট দেখায়।
   - ২ লাইনে প্রদর্শিত হবে, নিচে "আরও বিভাগ দেখুন / সংক্ষেপ করুন" টগল থাকবে।
   - ডাবল ক্লিকে এন্টার সুবিধা সংরক্ষিত থাকবে।

2. **মুহতামিম ড্যাশবোর্ডে "নোটিশ জারি করুন" বোতাম ও কম্পোজার:**
   - ড্যাশবোর্ড হেডারে "📢 নোটিশ জারি করুন" অ্যাকশন বোতাম।
   - নোটিশ কম্পোজারে টাইটেল, বডি এবং ১২টি বিভাগের মাল্টি-সিলেক্ট চেকবক্স (বা 'সকল বিভাগ' সিলেক্ট অল)।
   - জারি করা নোটিশ সংশ্লিষ্ট বিভাগের নোটিফিকেশন সেন্টারে সংরক্ষিত হবে।

3. **মুহতামিম পেন্ডিং অনুমোদন ও পারমিশন বোর্ড (Approval Center):**
   - পুরনো দায়িত্ব বণ্টন টেবিল অপসারিত হয়ে চলতি অনুমোদনসমূহ প্রদর্শিত হবে।
   - শুরুতে সর্বোচ্চ ৩টি অনুমোদন রিকোয়েস্ট প্রদর্শিত হবে।
   - "পরবর্তী অনুমোদনসমূহ দেখুন (+X টি অপেক্ষমাণ) ▾" বাটনে ক্লিক করলে লিস্ট প্রসারিত হয়ে স্ক্রোল করে দেখা যাবে।
   - প্রতিটি অনুমোদনে সরাসরি [✓ অনুমোদন দিন] এবং [✕ বাতিল করুন] অ্যাকশন।

4. **রুলস বিভাগে দুটি আলাদা অ্যাকশন বোতাম:**
   - "নতুন রুলস যুক্ত করুন" (পলিসি রুলস তৈরি)
   - "নতুন পারমিশন দিন" (স্টাফদের ডিপার্টমেন্টভিত্তিক পারমিশন প্রদান)
